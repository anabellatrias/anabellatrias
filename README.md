## 📂 Featured Projects

### 🔹 Amazon Best Seller Rank Prediction *(Capstone — Multimodal ML)*
**Tools:** Python, XGBoost, scikit-learn, TF-IDF, TruncatedSVD, Pandas

Built a multimodal ML pipeline to classify and regress Amazon Best Seller Rank using product images, text, and structured metadata — collaborating across a team of 4 with modular branch-based development.

- Owned the **NLP branch**: TF-IDF + TruncatedSVD pipeline with query-title alignment features, achieving a **7x improvement over baseline**
- NLP features were integrated alongside CNN image embeddings (teammate-owned) and structured data into a unified XGBoost model
- Achieved strong classification accuracy and R² ~0.30–0.45 on regression
- Managed full sprint documentation and contributed to final presentation and research poster

### 🔹 Weak Supervision for Bottleneck Detection
**Tools:** Python, scikit-learn, Pandas, Streamlit, Matplotlib, Jupyter

Built a validated weak-supervision pipeline to identify workflow bottlenecks with minimal labeled data.

- Engineered features including duration variance, queue behavior, and SLA deviations
- Designed rule-based labeling functions validated on held-out ground truth (F1=0.82)
- Trained a Random Forest on programmatically labeled data (2k samples) achieving **F1=0.989**
- Conducted business validation using domain signals: SLA breaches, rework patterns, and throughput lift

### 🔹 Gold vs. S&P 500 Outperformance Prediction
**Tools:** Python, Pandas, NumPy, Matplotlib, scikit-learn, XGBoost, Jupyter

Built a binary classifier to predict when gold outperforms the S&P 500 using 18 years of macroeconomic time-series data.

- Combined 11 macroeconomic + commodities datasets; engineered 40+ lag, rolling, and momentum features
- Trained Logistic Regression, Random Forest, and XGBoost with proper time-based splits
- Top model: Logistic Regression at **76% ROC AUC**
- Identified VIX, USD index, and treasury yields as key predictive drivers
